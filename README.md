# ことばの森 · KOTOBA NO MORI

一个按**场景与章节**学习日语词汇的静态网页，覆盖 **JLPT N5 / N4 / N3 / N2** 四个等级，共 **4656 个词条**。

## 打开方式

直接双击 `index.html`，或在浏览器中打开它即可。页面不需要安装依赖，也不需要启动服务器。

> 如果浏览器限制 `file://` 下的语音或本地存储，可以在当前目录运行任意静态服务器，例如：
>
> ```bash
> python -m http.server 8080
> ```
>
> 然后访问 `http://localhost:8080`。

## 手机端使用

页面已适配手机宽度，包含单列章节卡、可横向滑动的筛选条、全屏闪卡与底部快捷导航（场景 / 词汇 / 测验 / 错词 / 掌握）。

在手机浏览器中建议通过 HTTP 访问，而不是直接打开 `file://`：

1. 在电脑的项目目录运行 `python -m http.server 8080`
2. 用 `ipconfig` 查看电脑的局域网 IP，例如 `192.168.1.20`
3. 手机和电脑连接同一 Wi-Fi，访问 `http://192.168.1.20:8080`

如果部署到 GitHub Pages、Netlify 等静态托管，直接用手机访问网址即可。语音朗读和本地进度在不同手机浏览器上的支持略有差异，建议使用较新的 Chrome、Safari 或 Edge。

## 词库结构

- **N5：888 词**。由 `n5.docx` 的 50 个词表导入，按 10 个章节、50 个小节组织。
  - 章节：自我介绍、学校生活、工作、朋友、今天的饭、兴趣爱好、购物、休息日、居住、健康等。
  - 学习章节时可切换小节；词汇库支持按章节和小节筛选。
  - 原文档编号到 1000，但 50 张表中实际可读取 888 条；缺失编号未在文件中提供，因此没有凭空补写。
  - 少量词条在原表中没有例句，卡片会隐藏例句区。
- **N4：906 词**。由 `n4.docx` 的 41 个词表导入，按 8 个章节、38 个小节组织。
  - 章节：时间与生活、学习与工作、有趣的事、出门去吧、人际关系、健康与状态、何时何地、补充词汇。
  - 学习章节时可切换小节；词汇库支持按章节和小节筛选。
  - 两个补充表（动物、量词）没有例句，卡片会隐藏例句区。
- **N3：1316 词**。由 `n3.docx` 的 70 个词表导入，按 12 个章节、59 个小节组织。
  - 章节：人与人的关系、日常生活①②、我们的城镇、学习吧、工作、开心的事、为了健康、自然与生活、从新闻中学习、传达心情、传达形象。
  - 学习章节时可切换小节；词汇库支持按章节和小节筛选。
  - 职业补充表中的部分词条没有例句，卡片会隐藏例句区。
- **N2：1546 词**。由 `n2.docx` 的 60 个词表导入，按 12 个章节、60 个小节组织。

  - 学习章节时可切换小节；词汇库支持按章节和小节筛选。
- **总计：4656 词**，42 个场景主题。

## 功能

- **等级切换**：N5 入门、N4 基础、N3 进阶、N2 高阶，进度自动保存。
- **场景 / 章节学习**：N5 按 10 个章节、N4 按 8 个章节、N3 / N2 各按 12 个章节进入，可切换小节。
- **闪卡学习**：先想再看释义与例句；支持「记住了 / 还不熟」、上一张 / 下一张与键盘操作。
- **词汇库**：搜索日语、假名、中文释义或例句；按章节、小节、掌握状态筛选；每页 40 条，可继续加载。
- **掌握状态**：每个词显示「已掌握 / 未掌握 / 未学习」；已掌握为绿色，未掌握为红色，未学习保持原色。未掌握指已进入错词集的词。
- **小测验**：从当前等级随机抽 10 题，混合「日译中」与「中译日」选择题，记录最佳成绩。
- **错词集**：测验答错、点「不会」，或在闪卡中点「还不熟」都会自动归档；按等级和场景分组/筛选，支持逐词发音、移出、清空和错词重练。错词重练中答对会自动移出。
- **已掌握**：在闪卡中点「记住了」会自动归档；同样按等级和场景分组/筛选，支持逐词发音、取消掌握和随机复习。
- **本地进度**：已掌握单词、今日学习量、等级、测验成绩、错词集和已掌握记录保存在 `localStorage`，刷新后仍然保留。
- **语音朗读**：每个单词和例句都有朗读按钮，使用浏览器内置的日语语音合成（取决于系统是否安装日语语音）。
- **响应式布局**：桌面、平板与手机均可使用；手机端提供底部快捷导航。

## 修改词库

### N5

N5 词条位于 `n5-data.js` 的 `N5_WORDS` 中。每条词需要包含 `id`、`level`、`scene`、`section`、`word`、`reading`、`meaning`、`example`、`exampleZh`：

```js
{
  id: "n5-c01-s01-014",
  level: "N5",
  scene: "n5-self",
  section: "n5-c01-s01",
  word: "卵",
  reading: "たまご",
  pos: "",
  meaning: "鸡蛋",
  example: "卵を二つ買いました。",
  exampleZh: "买了两个鸡蛋。"
}
```

`scene` 使用 `N5_SCENES` 中的章节 id；`section` 使用 `N5_SECTIONS` 中的小节 id。新增词条后，章节与小节的计数会自动根据词条计算。
